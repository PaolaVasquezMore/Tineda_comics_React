Paso 2: Crear la app de React con Vite adentro de esa carpeta
Como ya estás dentro del repositorio, usamos el punto . para que instale React directamente aquí:

Bash
npm create vite@latest . -- --template react
(Si te pregunta si deseas sobrescribir o continuar en el directorio actual, presiona la tecla y y luego Enter).

Paso 3: Instalar las dependencias y Material UI
Bash
npm install
npm install @mui/material @emotion/react @emotion/styled @mui/icons-material
